# Maatsii LinReg MCP - Cursor Plugin Wrapper

Cursor plugin wrapper for the Maatsii LinReg MCP server.

- 200 live TradingView linear-regression fan charts
- - 64-setup trading playbook
  - - 11-section multi-timeframe technical analysis
   
    - Remote MCP endpoint: https://mcp.maatsii.com/mcp - no API key required.
   
    - ## Install
   
    - Add to your Cursor MCP config:
   
    - {"mcpServers":{"maatsii":{"url":"https://mcp.maatsii.com/mcp"}}}
   
    - ## Contents
   
    - - mcp.json - MCP server definition (https://mcp.maatsii.com/mcp)
      - - plugin.json and .cursor-plugin/plugin.json - Cursor plugin manifest
        - - skills/maatsii-linreg-ta/SKILL.md - skill instructions
          - - assets/logo.svg - logo
            - - LICENSE - MIT
